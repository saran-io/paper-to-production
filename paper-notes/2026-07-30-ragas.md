# RAGAS (2309.15217)

Date read: 2026-07-30 · Time spent: ~60m

## Claim

RAGAS evaluates RAG without reference answers. Faithfulness = decompose the answer into statements, check each against retrieved context, score as supported/total (`|V|/|S|`). It also defines answer relevance and context relevance — out of scope for Sprint 1.

## What would have to be true for this to help my system

- Answers are claim-like (prices, amenities), not pure chitchat
- Retrieved context is the intended ground truth for “faithful”
- We can afford a second LLM pass (or cheaper verifier) per eval
- We calibrate against human labels — the paper’s WikiEval agreement is not our domain

## What I'd measure

Cohen's κ between automated claim-support labels and human labels on listing cases. Secondary: raw agree, cost/eval, p95 latency, delta vs RAGAS library on the same set.

## Nuances

- Faithfulness ≠ world truth (wrong retrieval can still score high)
- Coarse statements hide partial hallucinations
- Exact match with humans overstates judge quality — pair with MVVP/κ
- Empty answers / no claims → undefined score (treat explicitly)

## Verdict

**BUILD** — reimplement the faithfulness loop; don’t wrap the library as the only path.
