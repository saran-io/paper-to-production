# Paper notes

Weekly notes for fast paper judgment.

These are not summaries. They are short decision memos answering:

- What problem is this paper trying to solve?
- Would that problem matter in this repo?
- What would I implement if I tested it?
- What metric would tell me it worked?
- Would I build, borrow, park, or reject it?

Use [`TEMPLATE.md`](TEMPLATE.md) for new notes.

## Standard

Every note should include:

1. The paper's real claim in your own words
2. The production issue it could help fix
3. Preconditions for it to matter
4. The metric that would falsify the claim
5. Failure modes and reasons not to use it
6. A verdict: `BUILD`, `BORROW`, `PARK`, or `REJECT`
