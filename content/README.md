# Content

Publish layer only. Engineering proof lives in [`builds/`](../builds/).

```
content/
├── SCHEDULE.md          ← all 10 publish dates
├── README.md            ← you are here
└── NN-title/
    ├── README.md        ← status + checklist for that post
    ├── blog.md
    ├── x-thread.md
    ├── linkedin.md
    ├── media/           ← finals you attach when posting
    └── _wip/            ← drafts / unused (ignore)
```

## How to ship one post

1. Open [`SCHEDULE.md`](SCHEDULE.md) → find the week  
2. Open that folder’s `README.md` → tick checklist  
3. Post from `blog.md` / `x-thread.md` / `linkedin.md` + `media/`  
4. Paste live URLs → mark **published**

## Cadence (every build)

| Surface | When (IST) |
|---|---|
| Blog | Tue 5:30pm |
| X thread | Tue 6:30pm |
| LinkedIn | Wed 8:30am (link in first comment) |

## Naming

Public language: **Build 01**, **Build 02**, … — not “sprint.”  
Repo folder: `builds/NN-title/`.

## Status

`drafting` → `ready` → `scheduled` → `published`
